# Student Performance Analysis 🎓

## About the Project
This project analyzes student marks using Python
and data analysis libraries.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Features
- Student marks analysis
- Average marks calculation
- Top-performing student identification
- Subject-wise performance visualization

## Dataset
This project uses a small sample dataset
created for practice purposes.

## How to Run

1. Install the required libraries:

   pip install -r requirements.txt

2. Run the Python file:

   python main.py
